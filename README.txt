ENEM PREP - SITE EDUCACIONAL COMPLETO
Versão HTML/CSS/JavaScript
================================================================================

ARQUIVOS DO PROJETO:
--------------------

PÁGINA INICIAL:
  - index.html .............. Página inicial do site
  - style.css ............... Estilos da página inicial
  - index.js ................ Lógica JavaScript da página inicial

PÁGINA DE MATÉRIA (LINGUAGENS E CÓDIGOS):
  - linguagens.html ......... Página de detalhes da matéria
  - linguagens.css .......... Estilos da página de linguagens
  - linguagens.js ........... Lógica JavaScript (abas, cards)

SISTEMA DE RESUMOS COM NAVEGAÇÃO:
  - resumo-literatura.html .. Página do sistema de resumos
  - resumo-literatura.css ... Estilos completos do sistema
  - resumo-literatura.js .... Sistema de navegação + 4 páginas de conteúdo

================================================================================
COMO USAR:
================================================================================

1. ABRIR O SITE:
   - Abra o arquivo "index.html" no seu navegador
   - Ou clique duplo no arquivo index.html

2. NAVEGAR PELO SITE:
   - Página inicial: Visão geral com todas as matérias
   - Clique em "Linguagens e Códigos" para ver os conteúdos
   - Na aba "Resumos", clique em qualquer card para acessar o sistema de resumos

3. SISTEMA DE RESUMOS:
   - 4 páginas de conteúdo completo:
     * Principais Autores Brasileiros
     * Escolas Literárias
     * Figuras de Linguagem
     * Modernismo no Brasil
   - Barra de progresso funcional (25% → 50% → 75% → 100%)
   - Navegação por sidebar com indicadores visuais
   - Página de resumo final ao completar 100%

================================================================================
CUSTOMIZAÇÃO:
================================================================================

Para customizar o conteúdo:
1. Abra os arquivos .js em um editor de texto
2. Localize as seções de dados (arrays com informações)
3. Modifique o conteúdo conforme necessário
4. Salve e recarregue a página no navegador

Para customizar as cores:
1. Abra os arquivos .css
2. Localize as variáveis CSS no início (--primary, --background, etc.)
3. Modifique as cores em hexadecimal
4. Salve e recarregue
